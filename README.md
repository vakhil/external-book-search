# External Book Search (Vercel App)

A lightweight, dedicated search and genre browsing portal connected to the Bookmark inventory database.

## Features
- 🔍 **Intelligent Book Search**: Instant search by Title, Author, or Book ID with live debouncing and cached query responses.
- 🎙️ **Voice Search**: Search books hands-free by speaking titles or authors.
- 🏷️ **Genre-Wise Browsing**: Interactive directory of common canonical genres with multi-genre collection and in-genre keyword filtering.
- 📖 **Live Book Covers & Synopsis**: Automatic 3D cover art display and on-demand book synopsis.
- 📍 **Shelf Wayfinder**: Shows physical shelf location (Rack, Column, Position) and availability status.
- 🚫 **Read-Only / Search-Only**: Strictly allows book exploration and genre browsing without book addition, cart/checkout, or modification capabilities.
- ☁️ **Vercel Serverless Ready**: 100% Python WSGI standard library runtime with zero heavy dependencies.

## Deployment to Vercel
Run inside this folder:
```bash
vercel
```
